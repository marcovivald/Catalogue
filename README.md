# AMAR · Catalogue

Interactive catalogue of AMAR Maison (Taif Al Emarat, Prima Chic), served at https://catalogue.amarmaison.com

- `/` detects the browser language (or the last one chosen) and opens `/it/`, `/en/` or `/de/`.
- The IT / EN / DE switcher in the top bar keeps the page you are on.
- `/pdf/` holds the printable PDF of each language (also linked from the bar).
- Images and fonts are shared by the three languages in `/assets/`.
- The site is not indexed by search engines (`robots.txt` + `noindex`): it is reached only by link.
